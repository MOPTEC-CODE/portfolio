WEB PROJECT

AccrueVG

Project Link: AccrueVG

Made With: React, Vite, Javascript, HTML, CSS

Description

AccrueVG is a personal web project that contains a record of my completed or uncompleted video games, known as a 'backlog'. The project also contains a list of various video game accomplishments that I find notable from my time spent playing video games. None of this is very important when it comes to my own pride, but I want a record for myself that I can combine with necessary front-end web developer skills.

Development

I was unhappy with the previous site I had been using for keep track of my backlog. I felt like it offered too many features. I wanted more of a simple list so I decided to create my own.

The main issue I encountered was finding a suitable API. Nothing worked for my specific situation so I used a mock API instead. I have JSON data hosted elsewhere that I fetch. I also had a design issue where I wanted to expand each entry by clicking on it. During this time, I accidently expanded each entry by setting their CSS class to 'expanded.' This ended up looking better and making more sense. I decided that this extra feature (albeit small) was unnecessary so it was removed.

Features

  • Uses effect, state, and fetch to retrieve and store data from a self-hosted mock API.
