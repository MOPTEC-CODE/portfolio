Tekworld Monsters Codex

Link: Tekworld Monsters Codex

Made With: HTML, CSS, JavaScript, JSON, TypeScript, Tailwind CSS

Project Description

Tekworld Monsters Codex is a worldbuilding and React/TypeScript/Tailwind CSS project exploring a hypothetical video game world that has run uninterrupted since 1991. Rather than building monsters around traditional fantasy elements, this project draws its creature designs and lore from the real-life experience of collecting and maintaining retro computer and video game hardware. Leaking capacitors, oxidized contacts, new-old-stock components, and modded hardware all contribute to the influence of the monster designs.

Development

I needed a web project that demonstrated my ability to use React. I have been studying React for awhile, initially creating a project over a year before this project began but I never published it. This project, Tekworld Monsters Codex, originally started as the Catholic Character Codex which would document Catholic characters in video games. I would still like to do that project some day, but I chose to wait. The amount of research that project would take is more than I'm willing to do right now.

This project also demonstrates my ability to use Typescript and Tailwind CSS. I wanted to create a project that incorporated a number of newer skills of mine into one. Using Tailwind CSS gave me a lot of real-world knowledge about the usability of a CSS Framework compared to regular CSS.

Features

  • A database containing information about each monster including a visual depiction.
  • A world map with a list of important locations.
  • Lore, influences, and goals.
