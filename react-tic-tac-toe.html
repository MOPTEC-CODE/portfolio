Tic-Tac-React Tutorial

Project Link: Tic-Tac-React Tutorial

Made With: React, Vite, Javascript, HTML, CSS

Description

Tic-Tac-React Tutorial is a project that follows a simple React Tic-Tac-Toe Tutorial from the official React website.

Development

My wife suggested I do this. I have a habit of rushing head-first and learning things myself while maybe missing out on some fundamentals. I learned a few new things from this but overall I was already aware of the concepts unique to React contained in this tutorial. I was able to finish this quickly. I wanted to make it more unique, since I was just following a tutorial, so I tried to recreate the style of Windows 95 through CSS.

Features

  • React states and hooks
  • A Windows 95-style interface
